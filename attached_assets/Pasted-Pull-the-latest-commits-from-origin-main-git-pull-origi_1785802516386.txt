## Newest fix (commit 0c2d299): active-signals / P&L page slowness
GET /api/active-signals was taking ~13 seconds to load, but its server-side cache TTL was only 12 seconds — the cache was expiring right as each slow computation finished, so it almost never served a cached hit and every page load paid the full cost. Widened the TTL from 12s to 60s in artifacts/api-server/src/routes/levels.ts. First load after deploy/cache-expiry will still take ~13s (that's real Yahoo/OKX fetch latency across ~125 symbol x timeframe combos), but repeat loads within a minute should now be fast.
